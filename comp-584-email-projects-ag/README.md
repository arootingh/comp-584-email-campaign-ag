##Email Campaign Overview

This project demonstrates a responsive, interactive email campaign built for **COMP 584**.  
It includes a hero section, two-column and three-column components, responsive stacking on mobile,  
and interactive elements like checkbox reveals, radio tabs, and keyframe animation.

###Features
- Two- and three-column responsive layouts  
- Mobile stacking via media queries  
- Keyframe animation using non-opacity properties  
- Checkbox reveal and radio-button interactivity  
- Inline CSS for maximum email-client compatibility  
- Accessibility reviewed (contrast, alt text, readable font sizes)
